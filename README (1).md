# AI Pioneers Internship — Week 1
## Python for Machine Learning & Data Preprocessing

### Project
**Data Preprocessing and Exploratory Data Analysis Using Python**  
Dataset: Titanic passenger training dataset (public Kaggle Titanic dataset mirror).

### Objectives covered
- Load and inspect tabular data with Pandas
- Use NumPy/Pandas for data analysis
- Identify missing values and duplicates
- Impute missing Age and Embarked values
- Remove columns not used as beginner model features
- One-hot encode categorical features
- Standardize Age and Fare
- Select candidate features and preserve `Survived` as the target
- Perform EDA with charts
- Export cleaned, encoded, and scaled datasets

### Run in Google Colab
1. Open `AI_Pioneers_Week1_Preprocessing.ipynb` in Google Colab.
2. Run **Runtime → Run all**.
3. The notebook downloads the dataset from a public GitHub mirror. If this fails, download `train.csv` from https://www.kaggle.com/competitions/titanic/data and upload it when prompted.

### Preprocessing decisions
- Missing `Age`: fill with median.
- Missing `Embarked`: fill with mode.
- `Cabin`: dropped because it has many missing values in this dataset.
- `PassengerId`, `Name`, and `Ticket`: dropped from the selected modelling table because they are identifiers/free-text for this beginner workflow.
- `Sex` and `Embarked`: one-hot encoded.
- `Age` and `Fare`: standardized using `StandardScaler`.
